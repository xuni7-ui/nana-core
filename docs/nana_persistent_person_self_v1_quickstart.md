## Review safely

No new paid quota or old key is used by this mission. Before live review, configure an explicitly authorized cognition route and safe FD/Resolver under a new bounded allowance. Existing UNKNOWN/no-retry and privacy gates remain in force. `--live` does not create permission or an unbounded budget.

For transient review:

```sh

```

For explicit retention of these new authorized PUBLIC/PROJECT review turns:

```sh
./nana chat --home /your/owned/home --retain-shared-life
```

This retains both utterances as reported speech with source dependencies. It does not import private history or authorize PERSONAL transmission. Do not mislabel personal relationship history as PROJECT to get it through the gate.
