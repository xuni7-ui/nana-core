## Assembly and changes

- Original LifeApplication, NanaRuntime, SubjectLoop and authoritative schema13
  Store, with existing ContextAssembler, CognitionSession, WorldModel,
  ConcernService, HandsWork, independent Verify, Experience/Growth and data-only
  skill sandbox. No second semantic loop or Subject state.
- `continuity/autonomy/private_intent.py` adds typed `PRIVATE_INTENT_V1` envelopes
  to existing INTENTION records, differentiated by contract discriminator and
  original intention/cycle/identity IDs. Source dependencies, supersession and
  privacy deletion use RecordService. No new tables/schema/dependency.
- Original C creates these only after an ENDORSED self-originated CREATE choice
  supported by CREATIVE_INTEREST. It can choose REST instead. The service cannot
  accept model-authored upserts or create Grants/Goals/actions. Its original intention lifecycle and attention-load accounting remain unchanged;
  disclosure status is an independent typed dimension.
- Disclosure policies include PUBLIC, PRIVATE_FOR_NOW, PRIVATE_UNTIL_TRIGGER,
  SURPRISE, MANAGER_AUDIT_ONLY, DISCLOSED and WITHDRAWN. V1 automatic formation is
  deliberately bounded: creative ideas and source-backed disclosure timing.
  No raw thought transcript or unrestricted hidden planner is stored. Revealing
  eligibility is not delivery, actual effect, or authority.
- Timed reveal is reconsidered in a later ordinary C cycle, with valid sources,
  current social boundary and busy/delivery checks. Inspect/clock/restart alone
  cannot reveal or send. Ordinary chat and Inspector do not receive private content.
  Existing truthfulness and Action-phase contracts remain applicable.
- Inspector retains mode=ro/query_only, privacy journal checks and bounded reads;
  adds private-activity metadata, action/Grant IDs, world-belief and skill metadata.
  It does not render raw reasons/purpose/model prose. Normal display explains the
  main sections; `--json` exposes IDs/source refs without credentials or content.
- Literal boundary baseline now recognizes “这个先别聊了” and “禁止再处理这个信息”;
  quotation/hypothetical uncertainty and conversation/processing separation remain.
- Dev CLI runs fail-closed preflight before launch, then uses existing foreground
  runtime/control socket. Live route requires separate authorization and explicit
  FD resolver; default offline mode is visibly limited, not naturalness-qualified.
- `journey.py` adds a setup hook to the existing owned-dev residency qualifier,
  combining source/semantic/correction/withdrawal, independent C, private idea,
  Manager veto, Inspector and dialogue refusal in the very same Store that later
  performs real owned work, learning, skill reuse, SIGKILL, backup and transfer.
  Semantic calls are SYNTHETIC_LOOPBACK, not a real Provider claim.
