## Decision

Self-Evolution and Companionship/Shared Life are both durable priorities. A small
verified capability change may receive current engineering priority; learning
is an available capability, never the Subject's mandatory highest motivation.
Self world, others' world and shared world intersect through sourced choices,
not engagement metrics. Warmth, playful accommodation and independent disagreement
are legitimate outcomes; none require fixed friendliness/refusal quotas.
Experiences must affect later capability/attention/choice, with counterfactuals.

One Subject, authoritative Store, SubjectLoop and Runtime. D WHEN; C WHAT/WHY.
Manager remains negative-only and independent of desire. Grant/privacy/Budget/
Verify/UNKNOWN/source correction and deletion retain existing authority. Primary
User significance is not permission. No Companion/Learning Brain or second planner.
H2-LIVE L1 qualification remains historical; no screen rerun is a completion gate.
No real provider, social integration, private memory or production access implied.

## Executable implementation contract

1. Add optional InteractionSignal to existing SubjectInput. This is a host-sourced
   interpretation (VENT/HELP/SHARE/DECLINE_DEPTH/REOPEN/FOCUS/UNCLEAR/IMPORTANT),
   not a model authority or claimed natural-language classifier. C derives
   context fit with source refs, scoped topic boundary and uncertainty. Ordinary
   vent/share does not become research/goal; explicit help permits consideration,
   not adoption/execution. Sourced project disagreement remains possible.
2. Keep refusal/reopen history in existing deletable SUBJECT_EVENT records using
   indexed target_id binding(entity,scope,topic). No new table/global blacklist.
   Later same-topic wake/learning work checks current boundary; explicit reopen
   permits reconsideration, not automatic work/retry. Unrelated own interests and
   pending work survive casual chatter. Focus request defers background work via
   existing D reactive priority; C does not erase independent desire.
3. LearningProblem contains only baseline/hypotheses/practice, never independent
   evaluation/transfer inputs/answers. Existing LearningSpec and nine stages stay
   evaluator-owned; old source records retained. Model LEARN path accepts only
   safe problem input (legacy full input is sanitized before transport).
4. Add derived growth-change assessment over active source-valid METHOD_SELECTION
   lesson and independently checked later reuse. Require novel input beyond all
   practice/evaluation/transfer inputs, fresh direct verification provenance,
   current privacy/scope and no unresolved counterexample. C can form a sharing
   or watch concern on a later ordinary D wake; actual recipient availability and
   source-topic refusal may defer it. No new Memory fact, mandatory sharing,
   renderer, delivery authority or auto-Goal from learning success.
5. Demonstrate actual controlled local computations and original governed local
   fixture ActionKernel work: baseline -> C-chosen learning -> independent heldout
   -> future local use -> experience/World evidence -> optional shared-life choice.
   Numeric strategy selection is bounded improvement, not invented algorithms or
   general real self-evolution. Separate capability and life-causality evidence.
6. Matched deletion ablation, changed inputs/context, busy/no-interest, independent
   counterexample, restart and fixture ModelPort comparison. Source withdrawal
   removes derived support; counterexample suspends applicability atomically.
   Existing CodeSkill sandbox/independent judge are not modified by candidates.

## Delivery/next real boundary

No Subject schema/table/dependency change planned. New optional DTO fields preserve
legacy input normalization/replay. All records use existing privacy dependencies;
projections are rebuildable and never independent support. Evidence is small text,
no DB or private content. Run targeted tests and final full default regression,
not historical H2 capture/300s soak again. Real dialogue requires a separately

permitted visible replies. Never read old chats/Iris or replace production speaker.
