# 后续独立复核中的明确输入反例

S8-C05/C06 进阶精修，固定对照 `45095c55`。原 G 先在数字案例中独立取得合格方法，后续有来源的复核发现新表示形式不符合该方法的输入契约。原程序抛出 WORLD_NUMERIC_INPUT_REQUIRED，未留下反例，既有方法仍可被选择。

现在原 EpisodeLearning 将 SYSTEM_VERIFICATION 来源上三类明确输入拒绝记录成有限反例。记录表示拒绝原因，不虚构计算结果。策略复核与原方法暂停在同一 Store 事务中提交。相同证据重放使用原结果，后续成功样本没有消除仍有效的反例。反例来源撤去后，仍须走原独立复验。普通陈述上的输入错误、其他错误和超时仍沿用原处理。

旧版目标 1 通过、1 失败。新源码共 35 项定向回归通过，覆盖原 G 选择和迁移、S3 后续动机、独立复验、来源撤回及既有 UNKNOWN。未调用真实模型，历史 b9a6569 便携候选未包含本修改。
