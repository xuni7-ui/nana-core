# 来源关联撤回

S1/S2 Advanced 与 Privacy。原删除日志、一次写事务、事件变更及副本传播沿用现行代码。SQLite 递归仅追到受影响的证据、同源记忆、衍生对象与支撑或版本引用。旧盲扫列表换成按已有和新增可重建反向索引走关系；冷副本仍可以丢弃该索引。独立内容保持可用。

固定 `46edafe` 的旧撤回方法与新方法在同一合成 schema13 投影上各锚定 3 次带原索引、3 次去可重建索引。两类各 3,000 条无关记忆和无关记录，保留 51 条受影响变更。12 次变更摘要相同，均无合成标记残留，原外键检查通过。带索引的撤回中位数 286→8 毫秒，去可重建索引 293→15 毫秒。Python 追踪峰值约 9.57→0.12 MiB。此样本新增反向索引分配 272 KiB。结果取自 SQLite 撤回事务，不把文件校验或跨设备传输算进去。
