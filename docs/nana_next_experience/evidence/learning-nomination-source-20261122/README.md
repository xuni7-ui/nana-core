# 原 G 的后续策略与提案归因

A / Advanced S2、S8、S10。固定原版 `4a145d3ae8b42477fb0e3c4ffb6b0eb8d913c210`。

原 G 可以用已独立验证的练习筛选策略为新的学习任务选方法。原 HYPOTHESIZE 无论策略是否已选出方法，都读取原模型提案端口的 `last_record_id`。端口仍保留上一任务的记录。旧版实际先通过本地 LEARN 产生另一任务的提案，再运行原 G 的后续任务。上一任务方法不同时，后续停留于 HYPOTHESIZE 并成为 UNKNOWN。方法相同时，后续完成却记录了无关提案作为来源。

现在只在本次 HYPOTHESIZE 调用模型提案端口时读取该端口记录。原策略分支保留本次实际采用的已验证策略记录。原练习选择、评价和迁移用例及资格门保持。不同方法与同名方法两个试验均从原 G 走到 DONE，在新食谱与距离样例通过独立评价与迁移。撤回上一任务专属模型来源，原提案失效，本次学到的方法仍有有效来源。每个样本总计一次本地 HTTP，属于上一任务，后续两侧均未额外调用，真实模型与计费未测。

保留首次夹具不适配的失败。诊断确定合成字符计数器下默认预算无法装入完整 LEARN 请求，改用现有同类本地 Provider 测试的默认计数后才得到有效的两个旧版失败。未更改业务预算、测试结果或旧 UNKNOWN。修改后相关 19 项通过，项目学习、私念选择/反馈、原 G、隐私和 Precision 另 52 项通过。历史数据已记录的旧提案关系不自动重写，已存在 UNKNOWN 也不重放。本补丁是策略来源完整性修复，尚未给出真实跨日 S10 增长资格。
