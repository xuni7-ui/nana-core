## Actual implementation / preservation

Reuse original memory_terms + existing privacy erasure and typed source/read guards. Bounded per-note trigrams and a complete marker are derived only for source-like direct SEMANTIC/STATEMENT note headers of at most4096characters. Candidate sets union indexed hits with ALL unindexed note headers (including old writers and long payloads); two-character query/missing-term-index paths retain exact scanning. Exact original literal/source qualification still precedes LIMIT. Per-note markers cannot certify facts. Source payloads are immutable; correction creates a new source. Suppression, withdrawal, privacy erase and old-version reindex remove these terms through the existing table lifecycle. No second Store, FTS engine, embedding model, schema table or permission authority.

One additive rebuildable covering header index avoids reading all payload headers before selective candidates. Its definition is checked; missing index falls back, wrong definition fails. Original B8 strips declared rebuildable indexes and reconstructs from source; new-current B8 continuity/withdrawal checks are included in targeted tests. Older binary export with a newer auxiliary index is NOT QUALIFIED; use the current exporter or a reviewed stopped-owner rollback that removes only this known rebuildable index. No production/old writer/rollback operation was performed.
