# 局部变化区域与原帧裁切实验

B负责，A基线90a31b6，隔离实验无现役消费者。输入为同尺寸的两张Pillow图，输出输入像素坐标的局部变化候选框；先以灰度变化中位数消去整体亮度平移，再以像素阈值找变化。稀疏噪声、大面积变化或分散到大范围的变化返回None。原帧裁切函数在内存中按原坐标裁出、1–4倍放大，输出源坐标/倍率；最长边限制1024像素。原图不落盘、不建立记忆或语义权威；调用者须绑定原帧来源、主体、隐私和时间，A/NanaLink各按原职责接线。Pillow为可选依赖。

实测：同分支暗场动态亮度12秒合成短文字片，FFmpeg真实解码的2.75→3.00秒帧；320×180、全局灰度位移26，得到框(17,16,79,36)，包含有字区域，可从3.00秒原帧裁切并放大。不是文字检测/OCR，也没有证明最终4帧会选择它。光标或其他局部运动也可产生框（测试明确记录）；大运动及分散变化的结果可能被拒绝，均不可被解释为无重要内容。

复现：`PYTHONPATH=src:. python -m pytest tests/nana_next_experience/test_video_local_change.py tests/nana_next_experience/test_video_short_detail.py -q`；扩展至覆盖、FFmpeg、换帧全部相关测试共23通过，FFmpeg/字体或Pillow缺失时相应测试明确skip。早期Pillow getdata弃用告警已改用tobytes，未改变断言。

单进程本地20次同一320×180合成帧比较，中位5.433ms、P95 6.384ms；单次Python tracemalloc峰值1,099,286字节、进程峰值RSS 15,896KiB（非单次增量，非设备/端到端成本）。不含解码、上载、模型及真实Token/费用。262144像素输入上限，算法全量遍历/排序，长视频逐帧使用成本尚未评估。图像尺寸、色彩/运动与压缩变化会影响结果，局部变化也不是有用文本；后续B必须用多样素材与同预算对照检验误报/漏报、短事件选择、字识别和资源，再交A/NanaLink评估接线。撤回本工具及测试即可，无数据迁移。
