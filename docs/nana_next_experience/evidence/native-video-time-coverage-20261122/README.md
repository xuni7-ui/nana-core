# 原 S5 固定预算的视频时间覆盖

A / Advanced S5、S2 和资源横轴。固定原版 `11d3107b9b6f2b83f4117e73dd5a29ae968c3433`。借鉴 B #22 `ee01bac73aa318f7a3ad47e4ccfbe9b817262e52` 中先保证时间覆盖的排序，对齐原 MediaDecoder 已实际测得的 PTS。从原隔离解码器改取样索引，保留原 FFmpeg 沙箱与 8 帧上限，不引入 B 原型的宿主过程。可改变已确认新视频的技术样本，不改写已持续化的旧观察。

原按帧索引配额均匀分布，密集 10fps 半段耗掉预算时，另一 1fps 半段几乎没样本。两段镜像合成片中的最大内部时间间隔是 5.5 秒、6.3 秒。现在保持首末实际帧和 8 个有序真实帧索引，变帧率用同一时间跨度的等距目标取附近实际帧，仅最大内部间隔确实变小时改用新样本。规则画面保留原索引并容忍一 tick 的量化，空白前后不推断，实际视频仍是部分取样，语义标记 UNKNOWN。
