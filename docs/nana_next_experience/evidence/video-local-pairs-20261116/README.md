# 局部变化的前后帧时间与回看候选

B负责，A基线35740e7；继承同分支已测的局部变化框。`propose(source_ref, frames)`接收调用方提供的同源原始 `(秒, PIL图)` 序列，对相邻帧计算局部变化，返回变化前/后各自真实输入时间、原像素坐标框、变化像素数与调用方提供的来源引用。没有返回帧/字幕/文本，没有持久化、网络或模型调用；来源身份、隐私、帧真实性及撤回必须由原NanaLink/Memory消费者在使用前重新核验，实验输出不能成为独立事实。

每批限制1200帧、单帧262144像素、总输入6400万像素、最多64个输出。候选超过限制时先按视频时间窗口分配，不能只让片头密集变化占满；返回实际遗漏数和`truncated`，遗漏仍是未观察/未选择内容。时间必须非负、有限且递增，帧尺寸必须一致。任意局部运动可能被提议，甚至鼠标也可能；候选不证明文字或语义重要性，不自动裁图/发送模型。上游若只有请求时间而未解码实际帧，不可伪造为实际输入帧。

可复现 `PYTHONPATH=src:. python -m pytest tests/nana_next_experience/test_video_local_pairs.py tests/nana_next_experience/test_video_local_change.py -q`：12通过（缺Pillow/FFmpeg/字体时相关用例明确skip）。FFmpeg真实解码的合成短文字片中，输出前后对2.75→3.0秒与3.0→3.25秒，两对框均(17,16,79,36)；3.0秒有字帧可按框从原始3.0秒图裁切，而非把3.25秒消失帧误当有字。此前4帧候选仍可能未选到该对，调用者不能忽略模型图片数/分辨率预算；若选两帧需承担额外图像成本，实际Token未测。
