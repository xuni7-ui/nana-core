## Gate A — CONTEXT_FIT_OFFLINE_CANDIDATE

InteractionSignal is an explicit **host interpretation**, not a natural-language
classifier or proof of what a human feels. Current fixtures submit typed VENT,
HELP, SHARE, DECLINE_DEPTH, REOPEN, FOCUS, UNCLEAR and IMPORTANT. Interpreted rather
than explicit signals require clarification; an inferred refusal cannot install
a persistent topic boundary. IMPORTANT without additional source support cannot
turn itself into an urgent authoritative fact.

C can attend/respond to a vent without offering research, consider explicit help
without adopting a goal, ask when uncertain, or prefer a project-supported
alternative over the user's proposed inefficient method. Sharing/playfulness
uses existing relationship evidence. Candidate SocialInteractionProposal has
`utterance=null` and `delivery_authority=false`; no natural reply/delivery is
claimed. A busy context can retain a wish but propose silence.

Refusal/reopen is scoped to entity/scope/topic via indexed existing record target
IDs. It affects later same-topic C wakes, private learning slices and already
adopted plan steps/reviews. Reopen permits reconsideration; it does not run old
work. Learning explicitly paused for this reason requires a fresh C endorsement.
Blocked F plan remains subject to existing explicit reconsideration, never an
automatic retry. Ordinary chatter leaves unrelated work/intention intact; focus
uses original D reactive priority to yield without discarding work.

Structured context and text are stripped from immutable queue metadata. An
ordinary TEMPORARY input can reach C through a bounded current-process envelope
with30-second eligibility; it is removed on completion/stop and is unavailable
after restart. It is not a second Memory store. Explicit boundary retention is
separate from ordinary conversation. DO_NOT_REMEMBER still wins; it cannot promise
durable refusal metadata while promising to retain nothing. Deleting the actual
boundary source removes that derived boundary; opaque historical receipts cannot
reconstruct its body. Hidden or exhausted boundary coverage conservatively blocks
deepening without exposing hidden content. Real topic resolution/semantic
classification requires later host/model qualification and is NOT_RUN.
