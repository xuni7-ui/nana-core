## What actually runs

One foreground `python -m nana_core.life run` process wraps original NanaRuntime.
No second subject/store/planner/context builder/learning framework. D supplies
opportunities and safe points; C still commits judgment/intention. Existing F/
Kernel/Manager/Grant/Budget/Verify execute actual approved project reads and local
artifact writes. Existing G stages and independent compiler evaluator select the
prewritten AST method after actual baseline coverage failure. A second real source,
absent from candidate practice/heldout/transfer, reuses it. Source-based later-use
assessment becomes an original C attention opportunity, not a forced social send.

Default portfolio only exposes configured finite real materials with sourced cues;
it is not a declaration of the Subject's personality/desires. Existing C can pause,
watch, refuse or rest. No-input completion happens in the resident real-wall-clock
Runtime without a developer repeatedly invoking work/reflect/advance. Initial init
approves material scope/finite local Grant once; restart never regrants or repeats
a completed request. Daily life remains bounded, not an open-ended curriculum.

## Modules / contracts

* `life/config.py`: typed host-local startup document, private atomic creation,
  resource detection and <=4-affinity/512MiB default address-space ceiling.
* `life/application.py`: trusted construction of original runtime, finite material
  opportunity source, filtered status/control, plain-text interaction, provider
  wiring and current verified report fact selection.
* `life/__main__.py`, `presentation.py`: human-readable foreground CLI plus JSON
  mode, bounded raw-FD input queue, safe signal/EOF exit. No Web listener/send.
* `life/provider.py`: explicit future host SecretResolver/credential-FD wiring,
  existing Router/Factory; disabled absent explicit hosts/privacy/budget/consent.
* Existing C context_fit accepts only a current source-correlated MODEL_PROPOSAL;
  request/revision/epoch/topic/support validation precedes judgment. Model meaning
  can suggest response mode but cannot invent explicit permanent user refusal.
* Existing CognitionSession INTERPRET/SOCIAL carry transient dialogue via typed
  volatile input, correlated strict proposals, same reservation/UNKNOWN semantics.
  Raw user body/free interpretation/reply wording are not persisted. Normalized
  local USER_STATEMENT metadata has a narrowly validated provenance domain; no
  raw PERSONAL/SECRET memory import. Known canaries absent from stored artifacts.
* Existing ContextAssembler pinned mode carries selected verified report facts
  and filtered relation/self projections without unrelated source corpus. Media
  source-only behavior unchanged. Model wording remains an unverified candidate;
  effect-status enum is not proof of arbitrary natural-language truthfulness.
* Existing D pause blocks background queue claims/opportunities/maintenance but
  permits reactive user processing and lease/health. Operational control metadata
  stays machine-local and is excluded by existing B8 package machinery.
* Existing LearningService now binds host evaluation source memories as erasure
  dependencies, while proposer still receives practice only. ProjectWork adds an
  independently checked later-use projection, no new authority/table.

No new dependency/migration: schema13,43 business tables. All private import,
negative-only Manager, Primary User significance, grants/budgets and model/resource
independence retained. Home config/provider/ports are not subject identity/memory.
