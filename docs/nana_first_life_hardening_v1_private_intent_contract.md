# Private intent / selective disclosure — design only, disabled by default

No new Subject schema, intention semantics, expression loop or private memory
store is introduced. Existing DisclosureDecision/IntentionDisposition remain the
sole cycle contracts. This document is preparation, not qualification of private
planning or human Shared-Life behavior.

Future application envelope may contain only: version, cycle/intention references,
category (idea/unfinished thought/surprise/private plan), status, source refs,
risk class, original normative disposition, realization gate refs, recipient scope,
and a source-backed reveal trigger. No raw model chain-of-thought, hidden reasoning
transcript, credential or unconstrained executable trigger is retained.

**Private from recipient != hidden from governance.** Ordinary recipient views may
show presence/category/status and risk/authority metadata when policy permits;
content defaults withheld. Governance/controller audit still sees external action
identity, scope, authorization, effect and uncertainty through existing boundaries.
This cannot hide an effect from Manager/Grant/Privacy/Budget/Verify.

Inspector V1 exposes neither purpose nor raw reason/model wording. It returns
`private_activity=UNKNOWN_CONTENT_NOT_EXPOSED`: a truthful lack of an established
private-activity projection, not a fabricated “no private thoughts” statement.
Existing visible disposition metadata is not a promise to disclose to a recipient.

A future reveal uses the original SubjectLoop's DisclosureDecision, source validity,
recipient privacy policy and delivery authority. Before/after/when asked/withhold/
decline/silence remain legal. WITHHOLD cannot assert a known falsehood; PLANNED,
MANAGER_BLOCKED, ACTION_BLOCKED, ATTEMPTED, UNKNOWN and VERIFIED_EFFECT are distinct.
A timer only offers reconsideration. It cannot reveal or send autonomously outside C.

Future tests, **NOT_RUN here**: sourced surprise→withhold→question→truthful decline;
source withdrawal cancels reveal; recipient changed/quiet hours defers; restart does
not duplicate delivery; Manager audit retains attempted effect; no Grant means no
effect; deleted source cannot be recovered from an audit/private snapshot. Reuse
existing disclosure, delivery and source lifecycle services; no implementation is
implied by this design. Any change to C semantics requires a separate scoped task.
