## Run it

Run from the repository with its existing environment. Explicitly select only
approved nonprivate project Python files. No file crawling or natural-language
model configuration is required.

```bash
.venv/bin/python -m tools.nana_real_life \
  --repo "$PWD" --state /tmp/my-project-review \
  --source src/nana_core/continuity/recurrence.py \
  --source src/nana_core/continuity/extensions.py \
  --lookup RecurrenceSpec.next_after \
  --practice src/nana_core/continuity/identity.py \
  --heldout src/nana_core/continuity/autonomy/requests.py \
  --transfer src/nana_core/continuity/subject/social.py \
  --allow-local-artifacts
```

The flag explicitly installs finite local dev Grants. Construction defaults to no
Grant; reopening alone does not grant/reexecute anything. Repeating the same CLI
request reuses committed goals/artifacts. A changed source digest is a new material;
a deleted source reference cannot be reimported under the same key. Missing or
corrupted already-exported output requires review, not automatic re-dispatch.
State/output directory must be outside input root, private, and used only by this
application. Limits:16 explicit source files,6144 bytes/file,96 bounded runtime
steps per phase. Exceptions fail closed; no arbitrary shell/path/network executor.
