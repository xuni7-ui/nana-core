# Rejected patterns / why

| 模式 | 可见来源/诱惑 | 主分类 | 具体坏处/安全替代 |
|---|---|---|---|
| 第二talking-self绕开SubjectLoop | YuriOS reactive brain与mind tick分工 | REJECT | 借cadence不借独立judgment authority |
| arrival log等于durable ingress | YuriOS SignalBus JSONL | REJECT | log不replay；保留Nana queue transaction/epoch |
| 每次tick必须LLM think | Anima agent.tick | REJECT | idle backoff仍持续付token；Nana NO_COGNITION保留 |
| dream/summary直接变truth/personality | YuriOS facts append、Anima selfrewrite | REJECT | proposal+source+admission+counter支持，不能自证 |
| Git历史=tombstone=彻底删除 | YuriOS forget、文件记忆历史 | REJECT | 旧敏感值仍在history；Nana隐私删除优先 |
| importance float决定自动purge | Anima downscale | REJECT | 模型/重复检索可左右保留权；retrieval decay与delete分离 |
| quiet时间越长越应该联系 | reach-out waiting/contact credit | REJECT as default | 静默不等于同意/孤独/关系恶化；提供source-backed机会 |
| timer prompt自动承诺 | language promise extraction/cron | REJECT | proposal/adoption/Subject reconsideration，非send直连 |
| checkpoint提供外部exactlyonce | durableframework误读 | REJECT | effect-before-ACK窗口；idempotency+Verify+UNKNOWN |
| 自动无限retry | Temporal默认attempts0、部分agent重试 | REJECT for unknown effects | 有界资源、先核验、确定未生效才考虑新尝试 |
| fallback新local agent=同一主体 | OpenWatari warm standby | REJECT for authority | central writer lease；无权fallback只能降级/只读 |
| user digital twin=Nana identity | Second-Me产品目标 | REJECT | 只借profile组织，Subject独立于用户 |
| risk score/allowlist=Grant | toolframework便利路径 | REJECT | hard scopes/Manager/Budget/Fence独立 |
| 关系/engagement总分 | 各类伴侣优化诱惑，未指控未读实现 | REJECT | multi-facet sourced、独立appetite、no authority |
| 直接copy AGPL/未明license code | Comma/未核实资产 | REJECT | 先license审查；当前只借机制 |

这些拒绝是Nana适配判断，不是宣称上游在其产品目标下必然错误。没有运行的failure path标UNKNOWN，不能用推断写漏洞定论。
