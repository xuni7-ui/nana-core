# Qualification limits

Development portable bundle, not production ready. No live cloud deployment,
production, social sends, private history, user device, paid provider or new live
call qualification is performed here. Foundation and prior selected-live results
remain in their original scope; HumanReview NOT_RUN, integration/Beta NO.

Tested only Linux x86_64/CPython3.12. ARM64, Windows, macOS, alternate Python/glibc
and genuine remote hosts NOT_RUN. Other supported Debian/Ubuntu combinations need
preflight; clean extraction/install is a fresh-host-like process on the current
Linux machine, not an independently purchased server qualification.

Python3.12+venv must be installed by the operator. No OS packages are installed.
Text runtime does not require ffmpeg; optional media/device adapters remain
unqualified/disabled. No systemd service is automatically installed and no hidden
background daemon or unrestricted tool capability is created.

The private remote experience entry is SSH into the server and the same CLI/IPC.
No new HTTP listener or public0.0.0.0 port, no new Web UI or authentication system.
Use your existing authenticated SSH/VPN; host login/security is the operator's.

First restore explicitly binds the included public example workspace, not old
machine paths or owned-app IPC handles. Unfinished work needs review and fresh
exact host capabilities/Grants; default runtime remains paused. Current project
status source is host-local and not copied as a personality or presumed current
SSOT. PROJECT_STATUS remote questions require an explicitly fresh approved
ProjectStateBinding; ordinary conversation/Inspector do not require one.

Backups are managed deletion-aware quarantined review copies. Do not activate a
copy as a clone. Lawful export retires the known old source and destination must
be clean. B8 cannot prevent a malicious trusted operator from copying archives to
multiple machines; distributed anti-copy/remote attestation is not claimed.
