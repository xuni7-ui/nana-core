# 视觉资源与角色扩展

## 用户原型

来源为用户本次上传的 `奈奈的小房间 __.html`。完整原型在只读附件中，未将原型代码或大段内嵌 base64 整包复制进应用。

`public/assets/nana-*.webp` 从原型中的九个角色差分提取并转换，约 19–20 KiB/张：

```text
neutral / sleepy / sad / angry / surprised
shy / happy / smile / mischievous
```

这些是用户提供素材的前端展示版本；不额外声称其商业授权、第三方署名或版权归属。后续公开分发或更换模型前，应由资源提供者确认相应使用权。应用代码使用的 npm 依赖保留其上游许可证，未把第三方运行库源码改称奈奈原创。

深蓝、紫色、柔粉、透明玻璃、轻盈动效、可爱而略带狡黠的角色氛围来自该原型。原型中的前端自动情绪、随机主动台词和“已记入记忆”模拟逻辑不作为真实主体行为复用。

## 场景插画

`public/assets/moonlit-room.webp` 为本次会话使用图像生成工具创作的月光书房概念插画（1672 × 940，216162 bytes）。已查看生成图并压缩为 WebP；原始生成 PNG 不随应用提交。插画仅为场景装饰，不暗示奈奈实际观察或经历了画中事件。

## 替换静态角色

使用有合法使用权的 WebP、PNG 或其他受支持图片，放在 `public/assets/`，并在 Avatar 图层的资源映射中替换路径。优先保持尺寸、比例和透明背景一致，提供恰当替代文本；避免把大型 base64 写入组件。

新增表情必须注明来源是允许展示的 Core projection，或明确的“界面预览”。不能把浏览器时间、随机数、关键词匹配或点击反馈称作奈奈的内在情绪。演示表情也应保留 DEMO 语义。

## Live2D 与媒体

当前是静态角色和可扩展容器；driver 接口为未来 mount/update/dispose、语音口型与页面展示模式留位置。接入真实模型还需：

- 合法模型与贴图、motion/expression/physics 等资源及对应格式。
- 兼容运行库和生命周期管理，离屏暂停、减少动效、失败回退与手机资源预算。
- 仅消费 Core 允许的表现状态或明确 UI 预览；语音口型来自播放进度，不产生情绪或主体判断。
- 若跨 frame 通信，固定可信 origin、校验消息结构并限制权限；不沿用原型的任意地址和 `postMessage('*')`。

`AVATAR_SUPPORTED` 不等于 `LIVE2D_CONNECTED`。图片、视频或音频附件展示也不等于已接通感知、语义理解或真实语音模型。
